# E&R — Our Private Space

تطبيق خاص يجمع **إياد (E)** و**روان (R)** لتنظيم حياتهما المشتركة: المناسبات، التقويم (ميلادي + هجري أم القرى)، خطة الشهر، المهام، المزاج اليومي، الدورة الشهرية (خاص بروان)، المطاعم والأماكن، قائمة الأمنيات، الرحلات، شهر العسل، المقاضي، المصروفات، والرسائل الصغيرة.

**الرابط:** https://e-and-r.media-buyer-control-center.workers.dev

### واجهة عربية بالكامل
- كل القوائم والأزرار والنماذج والتنبيهات بالعربية، والتصميم من اليمين لليسار.
- **الأرقام:** الإعدادات ← التقويم والتاريخ ← الأرقام: إنجليزية (123) أو عربية (١٢٣). يُطبَّق على كل الشاشات وعلى إشعارات الجوال.

### منذ أن عرفنا بعض ❤️
عداد مباشر يتحدّث كل ثانية: السنوات، الأشهر، الأيام، الساعات، الدقائق، الثواني منذ لحظة التعارف.
- يُحدَّد من **المزيد ← منذ أن عرفنا بعض** أو **الإعدادات ← مساحتنا** (التاريخ + الساعة بالدقيقة والثانية)، مع ذكرى وصورة.
- يُحسب حسابًا تقويميًا دقيقًا بالتوقيت المحلي (أطوال الأشهر الحقيقية والسنوات الكبيسة)، ويعرض التاريخ الميلادي والهجري، المدة الكاملة بالأيام/الساعات/الدقائق/الثواني، والذكرى السنوية القادمة.
- محفوظ في قاعدة البيانات ومشترك بين الحسابين، ويظهر كبطاقة في الرئيسية (يمكن إخفاؤها).

الصلاحيات (من يوافق، من يرد، اختيار الأمنية، تعليق كل شخص) مطبّقة على الخادم. كل إجراء يُسجَّل مع الاسم والوقت ويصل إشعار للطرف الآخر، ويمكن لكل شخص اختيار الإشعارات من الإعدادات.

### أعياد ميلادنا ❤️🎂
- كل شخص يرى **ميلاد الطرف الآخر فقط**: إياد يرى «يوم ميلاد روان» وروان ترى «يوم ميلاد إياد» (في الرئيسية وفي المزيد ← ذكرياتنا).
- التواريخ المحفوظة: روان 2004/02/27 (1425/01/07هـ) · إياد 2002/10/06 (1423/07/29هـ) — مطابقة لتقويم أم القرى. الميلادي هو المعتمد للعمر والعد التنازلي، والهجري الأصلي يُحفظ كما هو.
- العد التنازلي واليوم والتاريخ الميلادي والهجري لعيد الميلاد القادم، والعمر الحالي (بالسنوات والأشهر والأيام) والعمر القادم — كلها محسوبة تلقائيًا وتتحدث مع تغيّر اليوم.
- الرسائل تتغير حسب الأيام المتبقية، وفي يوم الميلاد تتحول البطاقة لتصميم احتفالي (قصاصات ونجوم خفيفة، بلا صوت)، ثم «خلص يومك…» لأيام بعده.
- **رسالة خاصة مخفية:** كل شخص يكتب رسالته للآخر من «إدارة أعياد الميلاد». الخادم لا يرسلها للمستلم قبل يوم ميلاده (بتوقيته)، والمستلم لا يستطيع تعديلها. يُشعَر الكاتب عند فتحها.
- **لوحة الإدارة** (الإعدادات ← أعياد ميلادنا): تواريخ الميلاد، رسائل العد التنازلي بنطاقات الأيام (إضافة/تعديل/حذف)، رسالة يوم الميلاد وما بعده، والرسالة المخفية.
- إشعارات قبل الميلاد بأسبوع و3 أيام ويوم، وفي اليوم نفسه.

## البدء (مرة واحدة)

1. افتح الرابط من الجوال ← تظهر شاشة **إنشاء المساحة**.
2. أدخل **رمز الإعداد** (`SETUP_TOKEN` — أُرسل لك في المحادثة، ويمكن تغييره بـ `npx wrangler secret put SETUP_TOKEN`)، واختر «إياد»، ثم البريد وكلمة المرور.
3. احفظ **رمز الاستعادة** الذي يظهر (لاستعادة كلمة المرور لاحقًا).
4. **الإعدادات ← دعوة الطرف الآخر** ← أرسل الرابط لروان. الرابط صالح 7 أيام ولمرة واحدة.
5. بعد انضمام روان تُغلق المساحة نهائيًا: لا يمكن إنشاء أي حساب ثالث.

### التثبيت على الجوال (PWA)
- **iPhone (Safari):** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **Android (Chrome):** القائمة ⋮ ← «تثبيت التطبيق».

### الإشعارات
- داخل التطبيق: أيقونة الجرس (تكليف مهمة، إنجاز، تعليق، رسالة، تذكيرات…).
- على الجوال حتى والتطبيق مغلق: **الإعدادات ← الإشعارات ← تفعيل**. على iPhone يجب تثبيت التطبيق على الشاشة الرئيسية أولًا (iOS 16.4+).
- التذكيرات تُرسل حسب ما تختاره لكل عنصر (نفس اليوم، قبل يوم، 3 أيام، أسبوع، أو وقت مخصص) — الدفعة اليومية في الساعة التي تحددها في الإعدادات (افتراضيًا 9 صباحًا بتوقيت الرياض).

### نسيت كلمة المرور؟
1. **رمز الاستعادة** من شاشة «نسيت كلمة المرور».
2. أو يطلب الطرف الآخر من **الإعدادات ← رابط إعادة تعيين كلمة المرور** ويرسله لك (صالح 24 ساعة).
3. (اختياري) عبر البريد: أضف `RESEND_API_KEY` كسرّ و`MAIL_FROM` كمتغير (حساب مجاني على resend.com).

## الخصوصية والأمان
- كل الصلاحيات مطبّقة على الخادم: لا وصول بدون تسجيل دخول، لا تسجيل عام، مساحة لشخصين فقط.
- **قسم الدورة:** بيانات روان لا تُرسل لإياد إطلاقًا (لا في المزامنة ولا التصدير). مشاركة «الموعد المتوقع» فقط اختيارية، وقفل برمز سري يُتحقق منه على الخادم.
- **المزاج:** «الملاحظة الخاصة» لا تظهر للطرف الآخر.
- كلمات المرور مشفرة (PBKDF2)، الجلسات بكوكي HttpOnly، حماية CSRF، ترويسات أمان وCSP صارمة.
- الصور تُصغَّر في المتصفح وتُحفظ في قاعدة البيانات ولا تُعرض إلا للطرفين.

## المزامنة المباشرة
كل تعديل يُسجَّل في سجل تغييرات؛ التطبيق المفتوح يجلب التغييرات كل 4 ثوانٍ (ولحظة العودة للتطبيق) ويعرض تنبيهًا مثل «روان أضافت مهمة». كل عنصر يحفظ من أضافه ومن عدّله آخر مرة.

## البنية التقنية

| الجزء | التقنية |
|---|---|
| الواجهة | PWA بـ JavaScript بدون إطار عمل (RTL، فاتح/داكن، يعمل من المتصفح ويُثبَّت) |
| الخادم | Cloudflare Worker (`worker/`) |
| قاعدة البيانات | Cloudflare D1 — `e-and-r-db` |
| التذكيرات | Cron كل 15 دقيقة + Web Push (VAPID) |
| الهجري | `Intl` بتقويم `islamic-umalqura` (أم القرى) مع تحويل في الاتجاهين |

```
public/          الواجهة: index.html, css/, js/ (pages/ لكل قسم), أيقونات، خطوط
worker/          الخادم: index.js, schema.js (تعريف كل الأقسام), routes/, cron.js
migrations/      هيكل قاعدة البيانات (يُولَّد من worker/schema.js عبر scripts/gen-schema.mjs)
tests/           api.test.mjs (48 اختبارًا) و ui.test.mjs (اختبار متصفح بمقاس جوال)
```

### أوامر
```bash
cd er
npm install
npm test            # اختبارات الـ API على قاعدة محلية مؤقتة
npm run test:ui     # اختبار المتصفح (لقطات في test-results/)
npm run dev         # تشغيل محلي: http://localhost:8787
npm run deploy      # بناء + ترحيل قاعدة البيانات + نشر
```

### إضافة حقل أو قسم
عدّل `worker/schema.js` (الحقول وأنواعها)، أضف ملف ترحيل جديد في `migrations/`، ثم صفحة في `public/js/pages/`. الـ API العام (`/api/c/:collection`) يتحقق من كل حقل تلقائيًا.

### حدود معروفة
- حجم الصورة/الملف بعد الضغط حتى 1.9 ميجابايت.
- عرض الأماكن على الخريطة يحتاج رابط Google Maps (الروابط المختصرة تُحلّ تلقائيًا).
- التوقعات في قسم الدورة تقريبية وليست طبية.
