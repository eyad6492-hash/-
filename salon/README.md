# Mr. Vibe Salon – مستر فايب

نظام ويب متكامل لإدارة صالون الحلاقة: الموظفون والصلاحيات، الدوام، الحضور والانصراف بالموقع GPS، الفواتير المصوّرة، النسب المستقلة لكل حلاق، المستحقات والدفعات، التقارير العامة، تقارير الموظفين PDF وإرسالها، الإجازات، الإشعارات، سجل العمليات، إغلاق الأيام والفترات، وتطبيق قابل للتثبيت (PWA).

**الرابط المنشور:** https://mr-vibe-salon.media-buyer-control-center.workers.dev

---

## التقنية

| الجزء | التقنية |
|---|---|
| الواجهة | PWA بلغة JavaScript بدون خطوة بناء، عربية RTL، Mobile-first، أسود وذهبي من الشعار الأصلي |
| الخادم | Cloudflare Workers — كل الصلاحيات والتحقق (المسافة، النسب، الإغلاق…) على الخادم |
| قاعدة البيانات | Cloudflare D1 (SQLite) — `migrations/0001_init.sql` |
| الملفات (صور الفواتير، إثباتات الدفع، تقارير PDF) | تخزين خاص: R2 إن رُبط، وإلا داخل D1. لا تُعرض إلا عبر الخادم بعد التحقق من الصلاحية |
| PDF | يُولَّد في المتصفح من تصميم HTML عربي (html2canvas + jsPDF) فلا يُعكس النص، مع فواصل صفحات بين الصفوف وترقيم |
| الخرائط | OpenStreetMap (عرض بدون مفتاح) + رابط Google Maps — لا يحتاج مفتاح API |

> اخترنا Cloudflare بدلاً من Next.js/Supabase لأنه نفس البنية المستخدمة في هذا المستودع وحسابك عليه، ويعمل بدون مفاتيح خارجية.

```
public/      الواجهة (صفحات، تصميم، أيقونات مشتقة تقنياً من الشعار الأصلي، Service Worker)
worker/      الخادم (API، المصادقة، الصلاحيات، الحضور GPS، الفواتير، التقارير، الإغلاق، المهمة الدورية)
migrations/  قاعدة البيانات
tests/       اختبارات API (60) واختبار واجهة بالمتصفح (27 خطوة على الجوال والكمبيوتر)
scripts/     تجميع الملفات، توليد الأيقونات من الشعار
```

## أول تشغيل

1. افتح الرابط ← تظهر شاشة **إنشاء حساب المدير** (مرة واحدة فقط).
2. أدخل رمز الإعداد `SETUP_TOKEN` (محفوظ كسرّ على Cloudflare) والاسم والبريد وكلمة المرور.
3. **الإعدادات ← إضافة موقع** الصالون: اضغط «استخدم موقعي الحالي» وأنت داخل الصالون، أو الصق رابط Google Maps، وحدد النطاق (مثلاً 100م).
4. **الموظفون ← إضافة موظف**: البريد، كلمة مرور مؤقتة (تُغيَّر عند أول دخول)، النسبة.
5. من ملف الموظف ← **الدوام**: جدول أسبوعي (يدعم الدوام بعد منتصف الليل، جداول مستقبلية، وتعديل يوم محدد).
6. أرسل الرابط للموظفين؛ كل شخص يدخل بحسابه ويثبّت التطبيق من «تثبيت التطبيق».

## ملاحظات مهمة

- **يوم العمل** يبدأ الساعة 5 صباحاً (قابل للتعديل): انصراف 2 ص يُحسب لدوام اليوم السابق.
- **النسب** تُجمَّد على كل فاتورة وقت تسجيلها؛ تغيير النسبة لا يغيّر الحسابات السابقة، ولا يُسمح بنسبة بتاريخ سابق توجد بعده فواتير.
- **احتساب الفواتير**: من الإعدادات — عند التسجيل (عدا المرفوضة) أو بعد الاعتماد فقط.
- **مكافحة الموقع الوهمي** (على الخادم): رفض الدقة الضعيفة والمواقع القديمة، تنبيه عند دقة غير واقعية، إحداثيات مطابقة لتسجيل سابق، انتقال غير منطقي، موقع شبكة بعيد عن الصالون، ساعة جهاز غير مضبوطة. كل محاولة مرفوضة تُسجل وتُرسل للمدير. لا يمكن لأي نظام ويب منع التزوير 100%، لذا تُعرض المؤشرات للمدير.
- **الإغلاق**: بعد إغلاق يوم/فترة لا يمكن تعديل الفواتير أو الدفعات فيها إلا لمن لديه صلاحية «التعديل بعد الإغلاق» مع كتابة سبب يُوثّق.
- **تنبيهات آلية** كل 15 دقيقة: من لم يسجل حضوره بعد فترة السماح، والغياب.
- الحذف ممنوع للبيانات المالية: الدفعات تُلغى مع سبب، وكل شيء في سجل العمليات (قبل/بعد).

## التخزين (يُنصح به)

حالياً الصور وملفات PDF محفوظة داخل D1 (حد الخطة المجانية 500MB ≈ آلاف الفواتير المضغوطة). للاستخدام الطويل فعّل **R2** من لوحة Cloudflare ثم:

```bash
npx wrangler r2 bucket create mr-vibe-salon-files
# أزل التعليق عن "r2_buckets" في wrangler.jsonc ثم
npm run deploy
```
الملفات الجديدة ستُحفظ في R2 تلقائياً، والقديمة تبقى تعمل من D1.

## التطوير والاختبار

```bash
npm install
echo "SETUP_TOKEN=local-token" > .dev.vars
npm run db:migrate:local && npm run dev     # http://localhost:8787
npm test                                    # 60 اختبار API
npm run test:ui                             # اختبار المتصفح + لقطات في screenshots/
npm run deploy                              # النشر
```

ربط دومين خاص: Cloudflare ← Workers ← mr-vibe-salon ← Settings ← Domains & Routes.
